# Bundled fonts

These files are compiled into the binary so that every icon and symbol in the UI renders
regardless of the fonts installed on the machine.

| --- | --- | --- | --- |
| `DejaVuSans.ttf` | DejaVu Sans | Bitstream, Inc. / DejaVu contributors | Bitstream Vera / DejaVu fonts license (permissive) |
| `NotoEmoji-Regular.ttf` | Noto Emoji Regular 3.002 | Copyright 2013 Google LLC | SIL Open Font License 1.1 |

The rest of the UI text uses egui's built-in fonts (Ubuntu-Light, NotoEmoji, Hack, emoji-icon-font).
